## 3. Irregularities and integration requests

> None of these block the merge, per the board rules. They are published here for the integration session
> (`arena-fe7c710c`) and for the user's manual review.

**IR-1 — `spt-larsen-pickleball`: cost cell is inferred, and the flag register contradicts the row.**
The cost cell reads `Free (no reservation fee — the courts are not reservable)`, but the official
directory publishes no admission value; the row's own notes derive the wording from "zero reservable
courts" + the department's $5/hour booking fee applying only to reservable courts. Under the project's
never-infer rule the cell should be blank with `status="unverified"` (or the wording moved to notes).
Additionally: `flag-larsen-address` says "The schedule, cost and street address are left blank" and
`xflag-f-051` says "the address field on the event row is blank" — but the row now carries both a cost
and `Carl Larsen Park, 850 Vicente Street`. Either the flag texts are stale or the row overstepped;
please reconcile. Evidence: [Pickleball Court Directory](https://sfrecpark.org/1772/Pickleball-Court-Directory),
[Pickleball](https://sfrecpark.org/1584/Pickleball), row notes in `data/events.py`.

**IR-2 — `spc-ai-week-sf-2026`: cost wording conflates a free directory with free admission.**
The cell reads `Free — the official site states the directory is '100% free to use'; each host-run event
sets its own entry rules and several are invite-only or guests-only`. "100% free to use" describes the
week-of-ai.com directory/RSVP, not event admission (the listing shows "guests only" and "invite only"
events). As written, `cost_class=free` puts the row in the free-only main list. Recommend rewording to
blank cost + unverified (admission per host) or an explicit "directory free; per-event admission set by
hosts" note outside the cost label. Evidence: [week-of-ai.com](https://week-of-ai.com/).

**IR-3 — `spt-larsen-pickleball`: `cost_class=mixed` is a classifier false positive.**
`scripts/focus.py::cost_class` marks the wording mixed because the paid-marker `"fee"` matches the
negated phrase "no reservation **fee**". If the cost is reworded/blanked (IR-1) this resolves itself;
otherwise a negation-aware marker would fix it.

**IR-4 — `rec-sfpl-summer-stride`, `rec-sfpl-one-city-one-book`: stale `page` metadata.**
Both rows carry `page="recurring"` but `group="annual"` (they are annual programmes). Rendering is
correct (`by_page` uses `group`, so they appear on `annual.html`), but the metadata field contradicts the
group. Recommend `page="annual"`.

**IR-5 — 28 rows marked `verified` with a blank schedule/location/cost cell.**
Confirmed unchanged and consistent with the published rule ("verified = every value the source publishes
was confirmed") and the existing review item `flag-verified-rows-with-blank-core-cell`. Listed in
`audit/row-audit-8eaf6c0a.csv` (verdict column `irregularity`). No action beyond the existing flag.

**IR-6 — domain hygiene:** `unionsquaresf.com` is now a parked/for-sale domain with ad injection and must
not be used as a source; `somarts.org/exhibition/diadelosmuertos*` redirects to a 2018 archive page (use
`somarts.org/exhibition/intheirname/` for the current edition).
