`data/events.py` and the preserved parallel-session rows), plus gap research for the three focus
areas the brief asks for — **gaming**, **music** and **AI** — with free events prioritised.

**Method.** Every value added or changed in this session was read off the organiser's, agency's or
venue's own page, fetched on 2026-10-18. Where a page did not publish a value (most often a ticket
price) the cell is left blank, the row is marked `unverified`, and a review item is published on
`flagged.html`. Nothing is inferred from aggregators, and no price, date or venue is completed from
a third party.

## 4. Line-by-line verification performed

### 4.1 Date parsing verified row by row

`scripts/focus.py` parses the published `dates` string of every row. All 114 rows with a parseable
date were printed and checked by hand against the source string. Two defects were found and fixed
during this review:

1. **Year-less day numbers picked up the wrong year.** `"April 10-11 and April 17-18, 2027"` was
   originally parsed as 2026. Fixed by selecting the year token nearest to the match.
2. **Month-year strings produced nonsense days.** `"September 2026 - May 2027"` was parsed as
   `2026-09-20` / `2026-05-20` because `\d{1,2}` matched inside the year. Fixed with a
   `(?!\d)` guard, after which the row correctly yields no day-level date.

Two **fabricated overrides were caught and removed** during this review: an invented
`2027-06-01` start for Stern Grove and an invented `2026-10-01`–`2027-01-30` span for the
Conservatory Light Show. Neither date appears in the rows' official sources, so both rows now
correctly report no confirmed date. The four remaining `DATE_OVERRIDES` were each checked against
the row's own published `dates` string and match it exactly.

### 4.2 Focus tagging

`FOCUS_BY_ID` in `scripts/focus.py` is an explicit id → tag map. Only rows whose own official source
describes them as a gaming, music or AI event are tagged. Rows that are merely AI-adjacent
(Dreamforce 2026, RSA Conference 2027, Cloudflare Connect 2026) are deliberately **not** tagged;
that decision is published as review item `flag-ai-adjacent-not-tagged`.

### 4.3 Reproducibility and link checks

- `python3 scripts/build_site.py` → `Wrote 16 pages, 228 events, 112 flagged items`; a second run
  leaves the working tree unchanged.
- `python3 tools/validate.py` → `events=228 verified=213 review_gap=15 review_items=112 domains=101
  pages=18` — OK.
- Local link / in-page anchor scan over all 18 HTML files → **0 issues**.
- Every new row's source URL is absolute HTTPS on the organiser's, agency's or venue's own domain;
  none is on the validator's blocked-host list.

source-link presence and local links; it does not fetch pages, so source freshness must be
re-checked against the linked official pages.
