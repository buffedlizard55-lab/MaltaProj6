3. What happens next

  • Nothing is hidden. Unverified rows stay in the category tables with blank values and an amber badge.
  • Corrections are cheap. Each row carries a stable ID (for example w-002 or a-010) that can be cited in a review request.
  • Re-verification date: all rows were checked on 2026-10-18. Seasonal and permit-based programmes should be re-checked before the next season.
